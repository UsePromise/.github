# Roadmap Pruning

Review planned and in-progress work against current evidence, product wedge, complexity cost, and opportunity cost.

For each item ask:
- What changed since this was added?
- Is there user evidence or only plausible-sounding value?
- Does it strengthen the core Promise model?
- What permanent surface or operational burden does it create?
- Can it merge into another initiative?
- What happens if we never build it?
- Is there a cheaper experiment that answers the key question?

Classify items as `continue`, `narrow`, `merge`, `defer until evidence`, or `drop`.

Prefer fewer simultaneous bets. Explicitly identify work kept alive by sunk cost, implementation momentum, competitive anxiety, or architectural curiosity rather than user/company value.
