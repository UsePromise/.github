# Promise contribution standards

This repository provides the default issue forms and contribution guidance for
repositories in the UsePromise organization.

- Product work is tracked in the [Promise project](https://github.com/orgs/UsePromise/projects/1).
- iOS implementation belongs in [UsePromise/ios](https://github.com/UsePromise/ios).
- Web, API, worker, AI, and infrastructure work belongs in
  [UsePromise/platform](https://github.com/UsePromise/platform).

Do not include credentials, private customer content, access tokens, or signing
material in issues, pull requests, logs, or screenshots.
